# Chapter 6 — Capstone: Restaurant Orders

Build a restaurant ordering program that combines input, arrays or collections, classes, validation, and totals.

- Starting reference: `src/WaiterList.java`
- Related practice: `src/Arrays/List/Menu.java`, `src/OOP/OnlineShopping.java`

## Requirements

- [ ] Display a menu with item names and prices.
- [ ] Let the user enter any number of customers.
- [ ] Record each customer's name and one or more food choices.
- [ ] Reject invalid menu choices and ask again.
- [ ] Print an itemized receipt for every customer.
- [ ] Print the total for each customer and the total for the restaurant.
- [ ] Keep menu items, customers, and orders in appropriate classes or collections.
- [ ] Keep asking for another order until the user chooses to finish.

## Stretch goals

- Apply a discount above a chosen order value.
- Print how many times each menu item was ordered.
- Save and reload orders from a text file.
- Split the bill across a user-selected number of people.

When the capstone works, try rebuilding it without looking at `src/WaiterList.java`.
