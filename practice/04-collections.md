# Level 4 — Collections

Use `ArrayList` when the number of values can change while the program runs.

## Task 25: Manage a resizable list

Add, read, update, remove, sort, and clear values in an `ArrayList`.

- Reference: `src/Arrays/List/ArrayListInJava.java`
- [ ] The displayed list reflects each operation.
- Stretch: store objects of a class you wrote instead of strings or integers.

## Task 26: Keep unique sorted values

Read five integers, discard duplicates, sort the remaining values, and print them.

- Reference: `src/Arrays/List/UniqueListSort.java`
- [ ] Duplicate inputs appear once in the result.
- [ ] The result is sorted from smallest to largest.
- Stretch: continue reading until the user enters a stop word.

## Task 27: Build a list menu

Create a menu that adds, removes, displays, and exits a list.

- Reference: `src/Arrays/List/Menu.java`
- [ ] The menu repeats until Exit is selected.
- [ ] Removing a missing value gives a useful response.
- Stretch: add options to search, clear, and display the list size.
