# Level 1 — Foundations

Learn to read input, store values, and produce clear output.

## Task 1: Birthday greeting

Ask for a person's name and age, then print a friendly birthday greeting.

- Reference: `src/Adams.java`
- [ ] A name and age are included in the greeting.
- [ ] An empty name is handled with a useful message.
- Stretch: print the correct age suffix (`st`, `nd`, `rd`, or `th`).

## Task 2: Read values with methods

Write one method that returns a name and another that returns an age. Use both from `main`.

- Reference: `src/Methods/GetAgeGetName.java`
- [ ] The name and age are read and displayed.
- [ ] One `Scanner` is shared for the input stream.
- Stretch: reject a blank name and a negative age.

## Task 3: Format a word problem

Display an age comparison using formatted text, ask the user to solve it, and report whether the answer is correct.

- Reference: `src/Concatenation/StringFormat.java`
- [ ] The displayed difference matches the values in the problem.
- [ ] Correct and incorrect answers get different responses.
- Stretch: read all ages from the user instead of hard coding them.

## Task 4: Format values in a sentence

Create a sentence from a name and age using Java's formatted output.

- Reference: `src/Concatenation/TemplateLiteral.java`
- [ ] Both variables appear in the sentence.
- [ ] The output ends with a newline.
- Stretch: format a decimal value to two places.

## Task 5: Compare a password

Ask for a password and compare it with a saved value using string content equality.

- Reference: `src/Arrays/Class/EqualsMethodPasswordCheck.java`
- [ ] The correct password is accepted.
- [ ] A wrong password does not trap the program in an endless loop.
- Stretch: allow three attempts and stop after the last failure.

When these tasks feel comfortable, continue to [Level 2](02-decisions-and-loops.md).
