# Level 3 — Methods and Arrays

Break a problem into methods and store related values in arrays.

## Task 17: Overload a method

Create two methods with the same name: one with no parameters and one that accepts a name.

- Reference: `src/Methods/Overloading.java`
- [ ] Java selects the correct method for each call.
- Stretch: add a version that accepts a name and a greeting style.

## Task 18: Pass objects to methods

Change a `Point` object inside a method and observe its coordinates after the call.

- Reference: `src/Methods/PointClass.java`
- [ ] The changed coordinates are visible to the caller.
- Stretch: compare this behavior with changing a primitive integer parameter.

## Task 19: Create and print an array

Ask how many integers the user wants to store, read them, and display the array.

- Reference: `src/Arrays/Class/ArrayEnterByUser.java`
- [ ] The array length matches the requested size.
- [ ] Every entered value appears in the output.
- Stretch: calculate the minimum, maximum, and average.

## Task 20: Store points in an array

Read x and y coordinates for several points, store them in an array, and display them.

- Reference: `src/Arrays/Class/PointArrayEnterByUSer.java`
- [ ] Every point is stored and printed in order.
- Stretch: find the point farthest from the origin.

## Task 21: Work with array contents

Create examples that initialize arrays, loop through them, and pass them to methods.

- References: `src/Arrays/AnonymousArrays.java`, `src/Arrays/PassingArrayToMethods.java`, `src/Arrays/List/ForEachLoop.java`
- [ ] The output shows each element in the correct order.
- [ ] A method can update array elements.
- Stretch: write a method that returns a copy without changing the original.

## Task 22: Sort, search, and compare

Sort arrays, search a sorted array, and compare arrays by their values.

- References: `src/Arrays/Class/SortingArray.java`, `src/Arrays/Class/SearchingArray.java`, `src/Arrays/Class/ComparingArrays.java`, `src/Arrays/Class/PrintingOFArrays.java`
- [ ] Search is performed only after sorting.
- [ ] Equal contents are recognized even when arrays are different objects.
- Stretch: sort a list of names without changing their original order.

## Task 23: Use variable-length arguments

Write a method that can sum either individual integers or an integer array.

- Reference: `src/Arrays/Class/VariableLenghArguement.java`
- [ ] Both call styles return the correct sum.
- Stretch: create a method that finds the largest value from a variable number of inputs.

## Task 24: Work with a two-dimensional array

Create a grid, print rows and columns, and handle rows with different lengths.

- Reference: `src/Arrays/TwoDimension/_2DArrays.java`
- [ ] Every row and column is displayed correctly.
- Stretch: calculate each row's total and the grid's total.
